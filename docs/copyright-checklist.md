# 저작권 자동 체크리스트 (콘텐츠 초안용)

초안을 완성하기 전에 아래 항목을 모두 점검하고, 항목별로 `통과 / 주의 / 수정필요` 판정과 이유를 기록한다.
이 체크리스트는 리스크를 줄이기 위한 보조 도구이며 법률 자문이 아니다. 판단이 애매한 항목은 "주의"로 표시하고 사용자가 최종 판단하도록 남긴다.

## A. 텍스트

1. **기사 전재 금지**: 뉴스 기사·블로그·리포트의 본문을 그대로 또는 일부 수정해서 옮기지 않았는가? 번역 전재도 동일하게 금지. → 사실(팩트)만 추출해 완전히 새 문장으로 재작성.
2. **표현 유사도**: 특정 출처의 문장 구조·표현·전개 순서를 따라 쓰지 않았는가? 한 출처에 의존하지 말고 3개 이상 출처를 종합해서 쓰면 자연히 회피된다.
3. **직접 인용 범위**: 인용은 비평·설명에 필요한 최소 범위(1~2문장)인가? 인용부호("")와 출처(매체명, 링크)를 명시했는가? 인용이 본문의 주(主)가 되면 안 된다.
4. **사실 vs 표현**: 단순 사실(주가 수치, 공시 내용, 사건 발생 자체)은 저작권 보호 대상이 아니다. 다만 그 사실을 서술한 기자의 표현은 보호 대상이므로 표현을 빌리지 않는다.
5. **공공 자료**: 정부·공공기관 발표자료(보도자료, 공시, 통계)는 대체로 자유 이용이 가능하지만 출처 표기 조건을 확인한다 (KOGL 유형 확인).

## B. 이미지·영상·차트

6. **타인 이미지 사용 금지**: 기사 사진, 방송 캡처, 타인 SNS 이미지, 인물 사진을 쓰지 않았는가? → 원칙적으로 전부 금지.
7. **차트·그래프**: 타 매체의 차트 이미지를 캡처하지 않았는가? → 원 데이터를 가져와 직접 새로 그린다 (데이터 출처 표기).
8. **대체 수단**: 이미지가 필요하면 ① 직접 생성(이미지 생성 스킬), ② 무료 라이선스(CC0 등) 확인 후 사용 + 라이선스 조건 준수, ③ 공식 보도자료 제공 이미지(제공 조건 확인).
9. **인물·초상권**: 특정 인물 이미지 사용은 저작권과 별개로 초상권 문제가 있으므로 사용하지 않는다.

## C. 데이터·수치

10. **수치 인용**: 시세, 통계, 실적 수치는 사실이므로 사용 가능하나 출처를 명시한다. 유료 리포트의 독점 데이터·분석 결론을 통째로 옮기지 않는다.
11. **표 재구성**: 타 매체의 표를 그대로 복사하지 않고, 필요한 데이터만 골라 직접 재구성한다.

## D. 표기·기타

12. **출처 섹션**: 초안 하단에 참고한 모든 출처를 [매체명 - 제목](URL) 형식으로 나열했는가?
13. **상표·로고**: 기업 로고 이미지를 장식용으로 쓰지 않는다. 기업명 텍스트 언급은 문제없다.
14. **커뮤니티 글**: 커뮤니티 게시글·댓글을 그대로 옮기지 않는다. 반응의 "경향"만 요약 서술한다 (예: "~라는 반응이 많았다").
15. **AI 생성물 표기**: 플랫폼별 AI 콘텐츠 관련 정책(예: X 수익화 정책)은 수시로 바뀌므로, 게시 전 사용자가 해당 플랫폼의 최신 정책을 확인하도록 안내 문구를 남긴다.

## 출력 형식

```
저작권 체크 결과 (자동 검토 — 법률 자문 아님)
- A. 텍스트: 통과 / 주의(사유) / 수정필요(사유+대안)
- B. 이미지: ...
- C. 데이터: ...
- D. 표기: ...
종합: 게시 가능 수준 / 수정 후 게시 권장 / 재작성 필요
```
