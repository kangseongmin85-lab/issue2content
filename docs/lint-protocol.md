# 자연스러움 3회 린트 프로토콜

목적: 초안을 "사람이 공들여 쓴 글" 수준으로 끌어올린다. 표현·문장·구성만 손대고
**사실·수치·출처는 절대 바꾸지 않는다.**

AI 사용 사실을 숨기는 용도가 아니다. 어색한 문장이 없는 글은 그 자체로 체류시간이 길다.

## 실행 방식

각 회차는 **독립 실행**한다 (Claude Code면 Task/서브에이전트, API면 별도 호출).
같은 컨텍스트에서 자기 글을 다시 보면 문제를 못 찾는다.

**전체 프롬프트를 회차별로 나눠 전달할 것** — 회차마다 체크리스트 전문을 다 주면
토큰 낭비 + 스코프 침범(2회차가 1회차 수정을 되돌림)이 생긴다.

### 1회차 — AI 패턴 제거
- 입력: 원본 전문 + `ai-patterns-checklist.md`의 **A·B절 + 위반 보고 형식**
- 작업: A(AI 패턴 1~15)·B(번역투 16~21) 전 항목을 문장 단위로 대조 → 수정
- 출력: ① 개정본 전문 ② 항목별 위반 건수 ③ 대표 사례 3개 이내

### 2회차 — 가독성·리듬
- 입력: 1회차 개정본 + 체크리스트 **C절 + 보고 형식**
- 축은 둘: ① 리듬(문장 길이 변화, 어미 반복, 낭독 시 걸림) ② 채널 톤(블로그=서술형 / X=단정적 훅)
- 출력: 1회차와 동일 형식

### 3회차 — 최종 검수 (신규 수정 금지, 복구·최소 교정만)
- 입력: **원본** + 2회차 개정본 + 1·2회차 집계 + 체크리스트 전문
- 검수:
  - 사실·수치·출처·`[내 코멘트]` 슬롯·투자유의문구 훼손 → 원본으로 복구
  - X 포스트 280자(링크·해시태그 포함) 초과 → 압축 (내용 추가 금지)
  - 잔여 위반 → 해당 문장만 최소 교정. 남으면 지적만 남기고 종료 (재실행 없음)
  - 과교정(밋밋해짐) → 1회차 이전 표현으로 복구
- 출력: 최종본 + 회차별 수정 요약 + 잔여 주의사항

## 합격선

- A·B 위반 0건. C 위반은 의도적 선택만 허용
- 주관적 항목(양비론·일반론·단어선택)의 재량 판정은 3회차 몫. 재량은 "위반 아님" 처리 권한이며, 위반으로 볼 때만 최소 교정
- 동일 형태 어미(`~했다`, `~습니다` 각각 별개 계산) 3연속 없음
- 한 문단 5문장 이하 / 문장 공백포함 80자 권장·100자 초과만 필수 분리(인용 제외)
- 첫 3문장 안에 훅 (단문은 첫 문장 기준)
- X 포스트 280자 이내

## 절대 금지

- 사실·수치·출처 변경, 근거 없는 내용 추가
- `[내 코멘트]` 슬롯 삭제·대필·위치 이동 (어미/문단 카운트에서도 제외)
- 직접 인용(" ") 내부 텍스트 수정
- 오탈자 삽입 등 탐지 회피 목적의 인위적 변형

## 여러 글 동시 처리

블로그 1편 + X 여러 포스트를 한 회차가 한꺼번에 받는다.
단 "한 편에 최대 1회" 같은 빈도 제한은 **글 단위**로 적용하고,
채널 톤 교차 비교(30번)만 글 간 비교로 수행한다. 톤이 같으면 X 쪽을 다시 쓴다.
