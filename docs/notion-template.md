# 노션 페이지 템플릿 (이슈당 1페이지)

페이지 제목: `[YYYY-MM-DD] 이슈명 — 콘텐츠 초안`

설계 원칙: 사용자의 발행 동작은 "노션에서 복사 → 플랫폼에 붙여넣기 → 발행"이다. 따라서 발행용 블록은 안내문·주석 없이 본문만 담고, 복사 범위가 명확하도록 블록을 분리한다.

## 페이지 구성 (위에서 아래 순서)

### 1. 상태 블록
- 상태: 🟡 초안 (사용자 검토 대기) — 사용자가 발행 후 🟢 발행 완료로 직접 변경
- 주제 분류: 전반 이슈 / 주식·투자
- 이슈 선정 이유: 화제성·지속성·경쟁 강도 평가 요약 (무인 실행이면 자동 선택 근거 포함)
- ▶ 린트 수정 요약 (접힌 토글): natural-writing-review 3회차의 회차별 수정 요약 + 잔여 주의사항

### 2. 이슈 요약 (5줄 이내)
- 무슨 일이 있었나 (확인된 사실만) / 왜 화제인가 / 핵심 숫자

### 3. 근거·출처 표
| 핵심 주장 | 구분 (확인된 사실 / 업계 추정 / 미확인) | 출처 | 링크 |
표 아래에 "미확인 루머" 목록을 별도 표기 (본문에 사용하지 않은 것 포함 — 사용자가 판단할 수 있게).

### 4. 저작권 체크 결과
copyright-checklist.md의 출력 형식대로 A~D 판정 + 종합 판정.
말미에 고정 문구: "자동 검토 결과이며 법률 자문이 아닙니다. 게시 전 플랫폼 최신 정책을 확인하세요."

### 5. 📋 X 발행용 (복붙 블록)
섹션 상단에 4.8단계에서 생성한 카드 이미지 2장을 삽입한다 (notion-create-file-upload → upload_url POST → image 마크다운 삽입, 상세는 image-cards.md). 이미지 위에 "어느 카드를 어느 포스트에 첨부할지" 안내 한 줄.

린트 통과한 최종본만. 포스트 1개당 코드 블록 1개 (블록 우상단 복사 버튼으로 통째로 복사되도록).

- **단독 포스트**: 코드 블록 1개, 280자 이내(링크·해시태그 포함)
- **스레드**: 포스트별 코드 블록, 블록 위에 순번 표기 (1/n, 2/n …). 마지막 포스트에 `[블로그 링크]` 자리 — 사용자가 블로그 발행 후 실제 URL로 바꿔 넣는다.
- [내 코멘트] 슬롯이 있는 포스트는 블록 위에 ⚠️ "코멘트 채운 뒤 발행" 표시

### 6. 📝 블로그 발행용 (복붙 블록)
린트 통과한 최종본만, 위에서 아래로 그대로 긁어 붙이면 되는 구성:

- 제목 (확정 1개 — 후보 3개 중 린트 후 최적안. 나머지 후보 2개는 아래 토글에)
- 본문 전체 (소제목 포함). [내 코멘트] 슬롯이 있으면 ⚠️ "코멘트 채운 뒤 발행" 표시를 본문 블록 바깥(위)에 표기 — 블록 안에는 복붙될 본문만 담는다
- 출처 목록 (본문 하단에 포함)
- 주식·투자 글이면 투자 유의 문구 (본문 하단에 포함)
- ▶ 참고 (접힌 토글): 제목 후보 2개, 메타 설명, 타깃 키워드 — 블로그 SEO 설정란에 입력용

### 7. 업로드 전 체크리스트 (사용자용, to-do 블록)
- [ ] [내 코멘트] 슬롯 전부 내 관점으로 채우기 (⚠️ 표시 확인)
- [ ] 핵심 수치·사실 1개 이상 직접 재확인
- [ ] 저작권 "주의" 항목 확인
- [ ] 블로그: 발행용 블록 복사 → 붙여넣기 → 메타 설명·키워드 입력 → 발행
- [ ] X: 블로그 URL을 `[블로그 링크]` 자리에 넣기 → 포스트 블록 순서대로 복사 → 발행
- [ ] 발행 후 상태를 🟢로 변경

## 생성 방법
- mcp__Notion__notion-create-pages 사용, parent는 사용자가 지정한 콘텐츠 페이지/DB.
- DB인 경우 속성(날짜, 상태, 주제)을 함께 채운다.
- 페이지 생성 후 사용자에게 페이지 링크 + 한 줄 요약을 보고한다.
